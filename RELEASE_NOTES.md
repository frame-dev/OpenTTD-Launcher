# OpenTTD Launcher 1.0.0 for Windows

Independent desktop launcher for official OpenTTD and JGR Patch Pack.

- Browse current and historical releases.
- Install versions independently, repair installations, and launch a selected game.
- Check Windows executable compatibility and support macOS bundles and Rosetta.
- Import local original TTD graphics and sound for legacy games.

This release is published for Windows. Extract the binary ZIP and run `launch.bat`. Java 21+ with desktop support must be installed and available as `java`; Maven is not needed to run the launcher.

Validated on Windows 11 x64 with Java 21: 50 tests passed and the packaged launcher started successfully. The two macOS-only tests were skipped. macOS and Linux support remains unverified for this release.

Internet is needed for downloads and release checks. Historical games may not run on current operating systems. Game data and Java are not bundled. Packages are unsigned.
